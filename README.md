# 🍸 GSAP Cocktails - Animated Web Experience

Welcome to the **GSAP Cocktails** project! This is a visually stunning, animated web application built to showcase the art of craft cocktails. Utilizing the power of React, Tailwind CSS, and GSAP, this project provides a dynamic and engaging user experience with smooth scrolling, masking effects, and beautiful typography.

## 🚀 Live Demo

Experience the live project here:
**👉 [GSAP Cocktails Live Demo](https://gsap-cocktails-chi-nine.vercel.app/)**

---

## ✨ Features

- **Modern & Premium Design**: Dark mode aesthetic with carefully chosen typography ("Modern Negra" and "DM Serif Text") and curated colors.
- **Advanced Animations**: Powered by [GSAP](https://gsap.com/) and `@gsap/react` for complex timeline animations, scroll-triggered reveals, and masking effects.
- **Fully Responsive**: Adapts seamlessly to desktop, tablet, and mobile displays using `react-responsive` and Tailwind CSS breakpoints.
- **Dynamic Content Sections**: Includes engaging sections like the animated Hero, popular cocktail selections, our story/about, artistic masking effects, and an interactive menu.

## 🛠️ Built With

This project leverages modern frontend technologies for optimal performance and developer experience:

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [GSAP 3](https://gsap.com/) & ScrollTrigger
- **Responsive Handling**: `react-responsive`

## 💻 Getting Started (Local Development)

If you'd like to explore the code or run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone <your-repository-url>
   cd new_project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **View the app**:
   Open your browser and navigate to the local server URL provided in the terminal (usually `http://localhost:5173/` or `5174`).

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the app for production to the `dist` folder.
- `npm run preview`: Bootstraps a local web server to serve the production build.
- `npm run lint`: Runs ESLint to catch issues in the code.
